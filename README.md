# Speed Tennis Ball Tracker

Система расчёта скорости теннисного мяча в реальном времени с использованием компьютерного зрения.

## Возможности
- Детекция и трекинг мяча в видеопотоке (YOLO)
- Расчёт скорости на основе перемещения между кадрами (30 FPS)
- Калибровка камеры с сохранением параметров в SQLite
- Отображение скорости в реальном времени (Tkinter)

## Стек технологий
- Python 3.10
- OpenCV, Ultralytics YOLO
- SQLite
- Tkinter
